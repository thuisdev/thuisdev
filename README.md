## Featured Projects 🚀

### 🤝 nexum: Decentralized Freelance Marketplace *(In development)*
A freelance job platform where client payments are locked in an on-chain escrow contract and released to the freelancer when the job is done. No trusted middleman needed.

- **Smart contracts**: Escrow, arbiter-based dispute resolution, checks-effects-interactions and access control
- **Frontend**: Responsive React app with wallet connection and pending / confirmed / reverted transaction states
- **Testing**: Foundry unit and fuzz tests, targeting 100% line and branch coverage
- **Stack**: Solidity · Foundry · React · wagmi · viem · Supabase
- **Links**: [Live app](https://nexum-gamma.vercel.app/) · [Repo](https://github.com/thuisdev/nexum)
